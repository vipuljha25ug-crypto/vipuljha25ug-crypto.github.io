Rethinking data and Information

March 23, 2026

In this unit we learned about data, information, knowledge and wisdom using the DIKW model. I had heard these terms before, but I never really thought about them properly. At first I thought it was a very simple concept because it looked like a clear step-by-step process. But after some classes, I started getting confused, especially between data and information. Sometimes both felt almost the same to me. In some examples shown in class, the same data was presented in different ways, and it actually changed how we understood it. That was something new for me. I also used to think that if we have more data, we will automatically get better knowledge. But after learning this unit, I don’t think that is always true. It depends more on how we understand and use the information. Just having data is not enough. In class I didn’t fully understand everything at first, but later when I discussed it with my friends, it became clearer. We also had slightly different opinions, which made me think more about the topic. In the end, I feel my thinking has changed a bit. Now I try to understand things more carefully instead of just accepting whatever is given.
