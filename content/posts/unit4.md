Typebot has allowed me to build a chatbot designed specifically to provide potential students interested in gaining admission to Azim Premji University with information through an interactive conversational style. Prior to undertaking this project, I took time learning about the typebot, experimenting with different blocks of content in order to understand the various types of information that would be useful in creating an effective way to communicate with users about potential admission opportunities and being familiarized with how the interface works and what different features (i.e., text messages, buttons, input fields) could be used to structure the flow of the conversation within the chatbot.There were a number of strategies used when planning how to structure the chatbot. I first came up with a general idea of the kinds of information like courses available, admissions process, scholarships, student life on campus, a prespective student would be interested in learning about and developed a menu of sections that would be included in the chatbot based on that information. I also addded a option where the chatbot is asking the name of the user and send a greeting message after to get a sense of familiarity.
I thought that typebot was simple to learn and use overall. I think the drag and drop options to build typebot was very easy to create blocks without using any programming language. Overall I will say that it was easy and fun to build this chatbot
